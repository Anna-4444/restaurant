# 🍽️ Restaurant Page

This project is part of the [Odin Project's JavaScript course](https://www.theodinproject.com/). The goal was to practice **DOM manipulation**, **modular JavaScript**, and **Webpack** by dynamically generating the content of a restaurant website — using **JavaScript only** (no hardcoded HTML content).

All elements in the <main></main> tag are created and injected into the DOM using JavaScript.

---

## 🔗 Live Demo

👉 [View the Live Site on GitHub Pages](https://anna-4444.github.io/restaurant/)  

---

## 🛠️ Features

- Content in the <main></main> tag created using **JavaScript DOM manipulation**
- **Tabbed navigation**: Switch between Home, Menu, and About pages
- **Modular code structure** using ES6 modules
- **Styled with CSS**, separated from JavaScript logic
- Bundled and built using **Webpack**
- Deployed via **GitHub Pages**

## 🚀 Getting Started

To run the project locally:

1. Clone the repo:
   ```bash
   git clone https://github.com/your-username/restaurant-page.git
   cd restaurant-page

2. Install dependencies:
   npm install

3. Start the development server:
   npx webpack serve

4. Visit http://localhost:8080
